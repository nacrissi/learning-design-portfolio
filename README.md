# Learning Design Portfolio

Workbooks, guided exercises, and class materials I wrote and designed during my wellness years.

**[Open the portfolio (PDF, 19 pages)](Jhinna-Salinas-Learning-Design-Portfolio.pdf)**

## What's inside

| Piece | Format | What the learner does |
|---|---|---|
| Energy Audit | Self-assessment workbook | Reads a short primer on four energy dimensions, checks off what applies, then maps what drains and what renews them on a worksheet |
| Daily Check-In Journal | Journaling guide | Morning, midday, and night prompts, with tips for building the habit |
| Embodied Magic | 7-day workbook | One activity a day: Wheel of Life, A Day in the Life, beliefs, energy, strengths, fears, integration |
| Listen: A Self-Massage Class | Class flyer | Promotional one-pager for a live class |
| Ho'oponopono Prayer | Writing prompt | A single guided letter-writing exercise |

Each piece pairs a short explanation with something to do right away: a checklist, a worksheet, a prompt, or a practice. Research-backed sections cite their sources on the page.
